CANboat documentation

CANboat decodes and encodes the CAN networks on boats: NMEA 2000 above all, and the SAE J1939 and Quick PCS buses some engines and windlasses speak. The NMEA 2000 database is closed, so CANboat's has been reverse engineered from observation and public sources since 2009. The source is on GitHub.

PGN documentation

Every message CANboat knows, field by field, with the enumerations they use:

  • NMEA 2000
  • SAE J1939: engines, gensets and transmissions
  • Quick PCS: Quick's windlasses and thrusters
